
# EcoSched 🌱

## An Intelligent Carbon-Aware Job Scheduling Framework for AWS Cloud

### Overview
EcoSched is a cloud-based job scheduling framework designed to reduce estimated carbon emissions by scheduling flexible computing workloads during periods of lower electricity carbon intensity.

### Objectives
- Integrate electricity carbon-intensity data.
- Develop a deadline-aware scheduling algorithm.
- Implement Greenest, Fastest and Balanced scheduling modes.
- Execute containerised workloads using AWS.
- Monitor execution and estimate carbon emissions.

### Technology Stack
